Simple explanation

Pythagoras is for right-angled triangles only. If the sides are a, b and c (where c is the longest side), then:

a² + b² = c²

Worked example (step-by-step)

Find c when a = 3 and b = 4

  1. Write the rule: a² + b² = c²
  2. Substitute: 3² + 4² = c²
  3. Calculate: 9 + 16 = c² → 25 = c²
  4. Square root: c = √25 = 5

Common mistakes

  • Using Pythagoras on a triangle that isn't right-angled
  • Mixing up which side is c (c must be the longest)
  • Forgetting to take the square root at the end
  • Rounding too early — do the square root last
